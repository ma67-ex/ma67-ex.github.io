## Run it on your device

No build step needed.

```bash
git clone https://github.com/ma67-ex/ma67-ex.github.io.git
cd ma67-ex.github.io
open index.html   # or just double-click the file
```

## Deploy

This repo is already deployed as a GitHub Pages site because it's named `<username>.github.io`. Any push to `main` goes live at [ma67-ex.github.io](https://ma67-ex.github.io) within about a minute. To run your own copy under a different name, enable **Settings → Pages** on your fork and pick the `main` branch.
