## What's on the site

Built with Next.js and exported to static HTML (no server required). Dark, near-black editorial design ("The Gilt Ledger"): Bodoni Moda for display type, Geist for everything else, hairline rules in place of cards, and a single gilt-brass accent color.

## Source

The Next.js source for this site lives in a separate working project and is exported (`next build` with `output: "export"`) into this repo's static files. This repo holds the built output that GitHub Pages serves directly.
